# YT Morphe

YT built with [RLX Patches](https://github.com/Ramik4/rlx-patches): all [Morphe](https://github.com/MorpheApp/morphe-patches) patches, voice-over translation, a built-in video and audio downloader and ready-made settings.

[![Latest release](https://img.shields.io/github/v/release/RAMiK4/yt-morphe?label=Download&sort=date&style=for-the-badge)](https://github.com/RAMiK4/yt-morphe/releases/latest)

</div>

## 🌟 Features

| | |
|---|---|
| 🧩 **RLX Patches** | All Morphe patches for YT with the RLX settings, icons and defaults |
| 🗣️ **Google and Yandex voice-over translation** | Listen to videos in your language (VoT) |
| ⬇️ **Video, audio, thumbnail and subtitle downloader with Save to device and offline SponsorBlock** | Download videos, audio (Opus / M4A), thumbnails and subtitles (SRT / VTT, also auto-translated) as files with a quality picker, and watch them offline with subtitles and SponsorBlock skipping: *RLX settings → Downloads → Save to device* |
| ⚙️ **Recommended settings** | A Premium-like experience from the first start. Your own changes are always kept; *RLX Customizations → Restore RLX default settings* restores them |
| 🔔 **In-app update check** | New builds are shown in the app: *RLX settings → Updates* |

The changes of each version are listed in the [releases](https://github.com/RAMiK4/yt-morphe/releases).

## 📱 Variants

| Variant | |
|---|---|
| **Amoled** (`…_Amoled.apk`) | All in-app themes, Pure Black / White by default |
| **Original_BBK** (`…_Original_BBK.apk`) | All in-app themes, Modern Dark / Soft Light by default, plus BBK Dynamic Island for BBK cn devices |

Both variants can be installed side by side. Theme colors can be changed at any time: *RLX settings → General*.

## 📥 Install

1. Download the APK of your variant from the [latest release](https://github.com/RAMiK4/yt-morphe/releases/latest).
2. Install it. To sign in with a Google account, [MicroG-RE](https://morphe.software/microg) is required.

Updates install over the previous version without losing data.
